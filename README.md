# Note App 🗒️

A draggable, resizable sticky note application built with React. Create, move, and organize colorful notes on your digital workspace.

## Features ✨

- **Drag & Drop**: Move notes anywhere on the screen by dragging the header
- **Custom Colors**: Each note has customizable header and body colors
- **Auto-resizing Textareas**: Notes expand as you type
- **Persistent Positioning**: Notes remember their location
- **Clean UI**: Minimalist design with smooth interactions
